# 潮汐：B站热搜演化实验室

热搜话题演化聚类与预警实验项目。数据为2026年10月公开历史归档。

## 打开方式

- **离线演示**：直接双击 `BiliTrend.html`。首页与四个子页面是独立HTML文件，须将全部 `BiliTrend*.html` 保持在同一目录。无网络依赖，支持搜索、统一时间回放、预警列表、三类曲线、聚类分布、模拟测试、输入校验和CSV导出。离线版使用Python预计算的各历史前缀结果，不在浏览器内重新训练。
- **完整服务**：在本目录终端执行：

```sh
python -m pip install -r requirements.txt
python app.py
```

浏览器访问 http://127.0.0.1:8765 。如端口被占用，使用 `python app.py --port 8766`。
服务只绑定本机地址。停止服务按 Ctrl+C。实时采集需联网；平台拒绝请求时会显示原因，不写入假数据。

## 功能

1. 统一历史时钟：只回放训练截止之后的时刻，榜单、预警、分布和已观察曲线同步变化。支持播放、暂停、速度切换和滑动定位。
2. 话题探索：当前榜单搜索、按模式筛选、完整已观察记录、相似标题关联依据。
3. 三类曲线：真实排名、由排名派生的热度指数、标题负面词倾向。可切换主图并同时查看其他两图，叠加历史代表前缀。
4. 预警中心：一级关注、二级疑似信号，展示触发时间、阶段、原因、条件性走向和命中词；可导出当前关注记录。
5. 模型实验：多维DTW、平均链接层次聚类、2—6簇比较，展示轮廓系数、辅助CH指数、当前榜单模式分布及各簇代表。
6. 实时采集：采集一次、每30分钟定时采集、停止与状态；保存到data/live，独立于历史训练集。关闭服务后停止。
7. 独立模拟：争议升级、反转振荡、观察不足。构造数据不混入真实训练/统计。
8. 输入校验：正常、异常JSON测试，不修改训练集。

## 方法与边界

- 444份快照、13320条排名记录，时间间隔中位数约1.38小时，不满足严格半小时采样；跨来源记录可能共享上游缓存，不能视为完全独立观测。
- 保留原始JSON及来源SHA，见data/provenance.json。原始归档来自Memory455/TrendRadar3、bobkingdom/TrendRadar、Jzoooooon/TrendRadar。
- 标题规范化精确匹配优先。相似关联仅在3小时内，字符匹配分至少0.84、双字片段重合至少0.65；拒绝否定/反转关键词不一致和难以区分的候选。只是保守字符串相似度，不是语义大模型。不同标题仍可能漏合并或误合并。
- 入模候选持续至少6小时且至少4点。所有短链仍在榜单中展示；间隔超过3小时重建链。离榜只代表快照未收录，不能解释成热度归零。
- 按完整轨迹结束时间选择约70%位置作为时间分界；从分界前已结束的长链确定性抽样最多120条训练。测试长链需在分界后开始。页面只展示分界后的回放，不用未来轨迹训练当前模型。
- 特征包含相对初始排名强度、每小时变化速度、弱权重排名水平、弱权重标题负面词分。归一化使用固定尺度，不使用未来峰值。
- 轨迹在自身实际小时范围内插值，最长36点。插值不会增加真实采样数量。DTW用欧氏局部代价并按两序列总长度缩放。CH在24点相对排名向量上计算，和DTW空间不同，仅作辅助。
- 最优簇数由可接受簇大小的候选轮廓系数选择。不强制得到课件全部五种类型。簇名按代表曲线形状解释，相同名称可出现多个簇。
- 当前模式使用历史代表轨迹对应时长的前缀匹配。距离不是置信概率，匹配过远/接近时标注暂定；短于2小时或不足3点不匹配。
- 排名热度指数由名次线性换算，不是平台热度；与排名并非独立证据。真实热度始终为空，不伪造搜索量。
- 标题负面词倾向只做词典命中加权，不代表公众情绪，不处理复杂否定、讽刺、上下文或真假。标题不变时曲线可能完全不变。
- 预警为规则：最近3点跨度不超过6小时；排名连续上升至少8位为升温，反向变化各至少6位为振荡。升温且负面词分严格连续增加为疑似争议升级；振荡且出现反转/澄清词为疑似反转振荡。不是经标注验证的舆情预测。
- 实时采集入口不保证平台可访问，也未在未积累数据时承诺实时舆情判断。当前可完整演示的是历史回放链路。

## 代码与复现

- engine.py：清洗、话题链、特征、DTW、聚类、前缀匹配、预警、模拟和回放数据打包。
- app.py：本地HTTP接口、模型更新、定时采集控制。
- collector.py：B站热搜请求，成功后保存，失败不写入。
- static/：页面、样式与交互代码。
- build.py：从原始数据重新训练并生成单文件HTML及data/bundle.json。
- test_project.py：时间隔离、未来数据独立性、指标、预警、输入与接口失败测试。

```sh
python build.py
python -m unittest test_project.py
```

## 5—10分钟演示建议

1. 展示项目名称、数据月份及来源。说明代理指标含义。
2. 播放统一时间轴，观察榜单与预警变化；点击预警，切换三种曲线并展开原始记录。
3. 查看当前模式分布和聚类评估，解释为什么没有强行设定五类。
4. 用独立模拟台展示疑似升级、疑似振荡和观察不足，再测试一份错误JSON。
5. 打开engine.py，讲解话题关联、DTW动态规划、模型时间划分和预警规则。
6. 说明失败案例：同事件换标题可能漏链；含“辟谣”的标题会命中负面词但不代表负面情绪；长采样空缺暂停预警。
